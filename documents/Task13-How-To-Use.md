## 🎯 功能使用指南

### 功能1: 收藏酒店（AI自动分类）

#### 使用步骤
```
1. 浏览酒店列表
2. 找到喜欢的酒店
3. 点击"❤️ 收藏"按钮
4. 等待1-2秒（AI分析中）
5. 查看AI分类结果
```

#### AI分类说明

**🏢 商务出行**
- 特征：市中心、会议设施、交通便利
- 示例：北京国际大饭店、上海外滩华尔道夫

**🏖️ 度假休闲**
- 特征：景区、度假村、休闲设施
- 示例：三亚亚龙湾度假酒店、杭州西湖国宾馆

**💰 性价比之选**
- 特征：价格实惠、评分不错
- 示例：如家快捷酒店、汉庭酒店

**👨‍👩‍👧 亲子家庭**
- 特征：家庭房、儿童设施、安全性高
- 示例：迪士尼主题酒店、亲子度假村

---

### 功能2: 分类筛选

#### 使用步骤
```
1. 进入"我的收藏"页面
2. 点击顶部分类标签
3. 查看筛选结果
```

#### 分类标签
```
[全部] - 显示所有收藏
[🏢 商务出行] - 只显示商务类酒店
[🏖️ 度假休闲] - 只显示度假类酒店
[💰 性价比之选] - 只显示经济型酒店
[👨‍👩‍👧 亲子家庭] - 只显示亲子类酒店
```

---

### 功能3: AI智能推荐

#### 使用步骤
```
1. 进入"我的收藏"页面
2. 滚动到页面底部
3. 查看"🤖 AI为您推荐"模块
4. 点击推荐酒店查看详情
```

#### 推荐依据
- 浏览历史（最近看过的酒店）
- 收藏偏好（已收藏酒店的特征）
- 订单历史（预订过的酒店类型）

#### 推荐数量
- 显示3个推荐酒店
- 每个酒店有AI推荐理由

---

### 功能4: 多选对比

#### 使用步骤
```
1. 在收藏页面勾选酒店复选框
2. 勾选2-3个酒店
3. 点击顶部"对比选中的酒店"按钮
4. 跳转到对比页面
```

#### 注意事项
- 最少选择2个酒店
- 最多选择3个酒店
- 建议选择同类型酒店对比

---

### 功能5: AI智能对比

#### 使用步骤
```
1. 进入对比页面
2. 查看顶部AI分析卡片
3. 查看底部对比表格
4. 根据AI推荐做决策
```

#### AI分析内容

**简短总结**
- 一句话概括酒店特点
- 示例："这三家酒店各有特色：上海外滩评分最高但价格较贵"

**核心差异**
- 价格差异
- 评分差异
- 设施差异
- 位置差异

**AI推荐**
- 🏆 最推荐：综合评分最高的酒店
- 💰 性价比之选：价格最优的酒店

#### 对比表格

**对比维度**
- 价格：越低越好（最低标🟢绿色）
- 评分：越高越好（最高标🟢绿色）
- 位置：文字描述
- 设施：列表展示

## 💡 使用技巧

### 技巧1: 提高推荐准确度
```
多浏览 → 多收藏 → AI越了解你 → 推荐越准确
```

**建议:**
- 浏览至少5个酒店
- 收藏至少3个酒店
- 完成1-2次预订

### 技巧2: 善用分类筛选
```
收藏很多时 → 使用分类筛选 → 快速找到目标
```

**场景:**
- 出差 → 点击"商务出行"
- 度假 → 点击"度假休闲"
- 预算有限 → 点击"性价比之选"
- 带孩子 → 点击"亲子家庭"

### 技巧3: 对比同类酒店
```
先分类筛选 → 再勾选对比 → AI分析更精准
```

**示例:**
1. 点击"商务出行"分类
2. 勾选3个商务酒店
3. 对比分析更有针对性

### 技巧4: 关注AI推荐理由
```
推荐理由 → 了解酒店特点 → 快速决策
```

**推荐理由示例:**
- "与您收藏的商务酒店风格相似"
- "高评分且价格适中"
- "位置便利，交通方便"

## 🎬 完整使用流程

### 场景：计划去北京出差

#### 第1步: 浏览酒店（1分钟）
```
1. 打开首页
2. 搜索"北京"
3. 浏览酒店列表
4. 点击查看几个酒店详情
```

#### 第2步: 收藏酒店（2分钟）
```
1. 收藏"北京国际大饭店"
   → AI分类：🏢 商务出行
   
2. 收藏"北京希尔顿酒店"
   → AI分类：🏢 商务出行
   
3. 收藏"北京如家快捷酒店"
   → AI分类：💰 性价比之选
```

#### 第3步: 查看AI推荐（1分钟）
```
1. 进入"我的收藏"
2. 滚动到"AI为您推荐"
3. 查看推荐酒店
4. 点击查看感兴趣的酒店
```

#### 第4步: 对比酒店（2分钟）
```
1. 点击"商务出行"分类
2. 勾选3个商务酒店
3. 点击"对比选中的酒店"
4. 查看AI对比分析
```

#### 第5步: 做出决策（1分钟）
```
根据AI分析：
- 预算充足 → 选择"最推荐"的酒店
- 预算有限 → 选择"性价比之选"
```

## ❓ 常见问题

### Q1: 如何访问收藏页面？
**A:** 点击导航栏"我的收藏"，或访问 http://localhost:5173/favorites

### Q2: AI推荐不准确怎么办？
**A:** 多浏览、多收藏，AI会根据你的行为不断优化推荐

### Q3: 对比页面加载慢怎么办？
**A:** AI分析需要几秒时间，如果超过10秒可能是网络问题，刷新重试

### Q4: 可以对比多少个酒店？
**A:** 最少2个，最多3个

### Q5: AI分类不准确怎么办？
**A:** AI分类准确度90%+，未来版本会支持手动调整

### Q6: 收藏太多怎么管理？
**A:** 使用分类标签筛选，或取消不需要的收藏

### Q7: AI推荐会更新吗？
**A:** 会的！推荐缓存30分钟，收藏变更后立即更新

### Q8: 可以取消收藏吗？
**A:** 可以，在收藏页面点击"取消收藏"按钮
