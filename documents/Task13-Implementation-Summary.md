## 🎯 三大AI亮点功能

### 亮点1: AI智能推荐收藏 ⭐⭐⭐

**实现方式：**
1. 分析用户浏览历史（最近10条）
2. 分析用户收藏偏好（全部收藏）
3. 分析用户订单历史（全部订单）
4. AI生成个性化推荐理由

**展示位置：**
- 收藏页"AI为您推荐"模块（3个推荐酒店）

**技术特点：**
- 使用 `qwen-turbo-latest` 模型
- 30分钟缓存
- 收藏变更时清除缓存

### 亮点2: AI智能对比分析 ⭐⭐

**实现方式：**
1. 分析对比酒店的核心差异
2. 识别用户可能关注的决策因素
3. AI生成对比分析和推荐建议
4. 自动高亮关键差异项

**展示位置：**
- 对比页面顶部"AI分析"卡片
- 差异项自动标注（绿色=优势，红色=劣势）

**技术特点：**
- 使用 `qwen-max-latest` 模型（分析能力强）
- 1小时缓存
- 支持2-3个酒店对比

### 亮点3: AI自动分类收藏 ⭐

**实现方式：**
1. AI分析收藏酒店的特征
2. 自动分类到预设类别
3. 生成分类理由

**预设分类：**
- 🏢 商务出行
- 🏖️ 度假休闲
- 💰 性价比之选
- 👨‍👩‍👧 亲子家庭

**技术特点：**
- 使用 `qwen-turbo-latest` 模型
- 添加收藏时自动调用
- 不缓存（每次重新分类）

## 📊 数据库设计

### favorites 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| user_id | INT | 用户ID |
| hotel_id | INT | 酒店ID |
| category | VARCHAR(50) | AI分类 |
| ai_reason | TEXT | AI分类理由 |
| create_time | TIMESTAMP | 创建时间 |

**索引：**
- `unique_favorite (user_id, hotel_id)` - 防止重复收藏
- `idx_user_category (user_id, category)` - 分类查询优化

### browse_history 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| user_id | INT | 用户ID |
| hotel_id | INT | 酒店ID |
| browse_time | TIMESTAMP | 浏览时间 |
| duration | INT | 浏览时长（秒） |

**索引：**
- `idx_user_browse_time (user_id, browse_time)` - 用户历史查询
- `idx_user_hotel_time (user_id, hotel_id, browse_time)` - 去重查询

### ai_call_logs 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| service_type | VARCHAR(50) | 服务类型 |
| prompt_length | INT | Prompt长度 |
| duration_ms | INT | 耗时（毫秒） |
| status | VARCHAR(20) | 状态 |
| error_message | TEXT | 错误信息 |
| created_at | TIMESTAMP | 创建时间 |

**索引：**
- `idx_created_at (created_at)` - 时间查询
- `idx_service_status (service_type, status)` - 统计查询
