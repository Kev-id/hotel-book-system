# 🤖 AI增强评价系统 - 使用指南

## 🎉 欢迎使用AI增强评价系统！

本系统通过AI技术全方位增强酒店评价功能，提升用户决策效率和商户运营效率。

---

## 🚀 快速开始

### 1. 启动服务

```bash
# 启动后端（终端1）
cd backend
npm start
# 后端运行在: http://localhost:5000

# 启动前端（终端2）
cd ..
npm run dev
# 前端运行在: http://localhost:5173
```

### 2. 访问页面

**用户端 - AI评价摘要**:
```
http://localhost:5173/detail/1
```
在酒店详情页面，滚动到"酒店介绍"下方，即可看到AI智能摘要卡片。

**管理端 - AI功能演示中心**:
```
http://localhost:5173/admin/ai-demo
```
体验所有AI功能：评价摘要、智能回复、趋势分析、质量检测。

## 🎯 核心功能

### 1. 📊 AI评价摘要
**位置**: 酒店详情页

**功能**:
- 自动分析最近30条评价
- 生成智能摘要（100-150字）
- 提取优点和缺点
- 情感分析（好评/中评/差评占比）
- 高频关键词标签

**用户价值**: 快速了解酒店真实情况，节省80%阅读时间

### 2. 💬 AI智能回复
**位置**: AI演示中心

**功能**:
- 生成3种风格回复（专业/友好/补偿型）
- 针对性建议（好评/差评不同策略）
- 一键复制
- 回复技巧提示

**商户价值**: 提升70%回复效率，改善客户关系

### 3. 📈 AI趋势分析
**位置**: AI演示中心

**功能**:
- 评分趋势（上升/下降/稳定）
- 维度评分展示
- 热点问题识别
- AI洞察建议

**商户价值**: 发现运营问题，数据驱动决策

### 4. 🔍 AI质量检测
**位置**: AI演示中心

**功能**:
- 规则检测（全5分、内容过短、用户历史）
- AI深度检测（真实性、评分内容匹配）
- 权重评分（100分制）
- 置信度计算

**商户价值**: 识别虚假评价，保护品牌声誉

2. 输入评价内容和评分
3. 点击"生成回复建议"
4. 选择合适的回复风格
5. 一键复制使用

**效果**: 提升70%回复效率，专业形象展示

### 场景3: 商户分析趋势
1. 访问AI演示中心
2. 切换到"趋势分析"标签
3. 选择时间范围（7/30/90天）
4. 查看评分趋势和热点问题
5. 根据AI洞察改进服务

**效果**: 发现问题趋势，持续改进服务

## 🆘 常见问题

### Q1: AI摘要显示"暂无足够评价"？
**A**: 该酒店评价数量不足30条，无法生成AI摘要。

### Q2: AI服务响应很慢？
**A**: 首次调用会比较慢（无缓存），后续调用会使用缓存，速度会快很多。

### Q3: 显示"AI服务暂时不可用"？
**A**: AI服务暂时不可用，系统已自动切换到降级模式，显示基础统计数据。

### Q4: 如何刷新AI摘要？
**A**: 点击AI摘要卡片右上角的刷新按钮，可以强制刷新缓存。

### Q5: 限流错误（429）？
**A**: 调用过于频繁，请等待1分钟后重试。不同角色有不同的限流策略。
