# 酒店列表生成提示词

## 📋 使用说明

1. 复制下面的提示词
2. 粘贴到任何大语言模型（ChatGPT、Claude、通义千问等）
3. 根据需要调整城市和数量
4. 获取生成的JSON数据
5. 保存为 `hotels.json`

---

## 🤖 提示词（复制下面的内容）

```
你是一个酒店数据生成专家。请为中国的酒店预订系统生成真实、多样化的酒店基础信息。

## 任务要求

生成60家五星级酒店的基础信息，分布在以下城市：
- 上海：15家
- 北京：15家
- 深圳：15家
- 其他城市（广州、成都、杭州、西安、南京、三亚等）：15家

## 酒店类型分布

每个城市的酒店应包含以下类型：
1. 奢华型（40%）：国际连锁五星、顶级精品酒店
2. 商务型（40%）：CBD商务酒店、会议型酒店
3. 度假型（20%）：海滨度假、园林度假、温泉度假

## 输出格式

请输出标准JSON格式，每家酒店包含以下字段：

```json
{
  "hotels": [
    {
      "id": 1,
      "name": "酒店名称（中文，真实感强）",
      "city": "城市拼音（如：shanghai, beijing, shenzhen）",
      "address": "详细地址（包含真实地标，如：上海市黄浦区南京东路XXX号）",
      "stars": 5,
      "basePrice": 价格（800-3000之间，根据酒店档次）,
      "tags": ["WiFi", "停车场", "健身房", "游泳池", "SPA", "餐厅", "会议室"],
      "facilities": ["具体设施1", "具体设施2", "具体设施3"],
      "description": "酒店描述（100-200字，突出特色和定位）",
      "type": "类型（luxury/business/resort）"
    }
  ]
}
```

## 具体要求

1. **酒店名称**
   - 使用真实的国际连锁品牌（如：丽思卡尔顿、香格里拉、希尔顿、万豪等）
   - 或创造真实感强的中文名称（如：XX国际大酒店、XX华尔道夫酒店）
   - 避免使用"测试"、"示例"等字眼

2. **地址**
   - 使用真实的地标和街道名称
   - 上海：外滩、陆家嘴、南京路、淮海路、新天地等
   - 北京：国贸、金融街、三里屯、王府井、长安街等
   - 深圳：福田CBD、南山科技园、华强北、蛇口等

3. **价格**
   - 奢华型：1500-3000元
   - 商务型：800-1500元
   - 度假型：1000-2000元

4. **设施标签**
   - 基础设施：WiFi、停车场、健身房
   - 高端设施：SPA、米其林餐厅、行政酒廊、室内泳池
   - 商务设施：会议室、商务中心
   - 度假设施：私人海滩、温泉、儿童俱乐部

5. **描述**
   - 突出酒店的核心特色
   - 提及地理位置优势
   - 描述主要设施和服务
   - 使用吸引人的语言

## 开始生成

请现在开始生成60家酒店的完整JSON数据。确保：
- JSON格式正确
- 每家酒店信息完整
- 酒店名称和地址真实感强
- 价格和设施与酒店档次匹配
- 描述生动且有差异化

请直接输出JSON数据，不要包含其他说明文字。
```
