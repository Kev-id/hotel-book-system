让收藏功能正常工作！

在开始之前，请确认:

## 🚀 第一步: 启动后端

### 1.1 打开命令行窗口

Windows: 按 `Win + R`，输入 `cmd`，回车

### 1.2 进入后端目录

```bash
cd D:\Downloads\hotel-book-system-master\hotel-book-system-master\backend
```

**注意**: 请根据你的实际路径修改！

### 1.3 启动后端

```bash
npm start
```

### 1.4 检查输出

**✅ 成功的输出:**
```
Server is running on port 5000
✅ 数据库已存在，跳过初始化
```

**❌ 如果看到错误:**

#### 错误1: npm不是内部或外部命令
```
解决: 安装Node.js
访问: https://nodejs.org/
下载并安装LTS版本
```

#### 错误2: Cannot find module
```
解决: 安装依赖
npm install
然后再次运行 npm start
```

#### 错误3: 数据库连接失败
```
解决: 检查MySQL是否运行
检查 .env 文件中的数据库配置
```

### 1.5 保持窗口打开

**重要**: 不要关闭这个窗口！后端需要一直运行！

## 🔍 第六步: 排查问题

### 如果收藏失败，按照以下步骤排查:

#### 6.1 检查Network请求

在 Network 标签中，找到 `add` 请求

**检查Status Code:**

- `200`: 成功 ✅
- `400`: 参数错误或已收藏 ⚠️
- `401`: 未登录 ❌
- `404`: 路由不存在 ❌
- `500`: 服务器错误 ❌

#### 6.2 查看Response

点击 `add` 请求，切换到 `Response` 标签

**成功时应该看到:**
```json
{
  "success": true,
  "message": "收藏成功",
  "category": "💰 性价比之选",
  "reason": "价格实惠"
}
```

**失败时会看到:**
```json
{
  "error": "错误信息"
}
```

#### 6.3 检查Console错误

切换到 Console 标签，查看是否有红色错误信息

**常见错误:**

##### 错误1: Failed to fetch
```
原因: 后端没有运行
解决: 回到第一步，启动后端
```

##### 错误2: 401 Unauthorized
```
原因: 没有登录或token过期
解决: 回到第四步，重新登录
```

##### 错误3: Network Error
```
原因: 后端地址不对
解决: 检查后端是否在5000端口运行
```
