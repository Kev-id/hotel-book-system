# AI智能回复集成说明

## 🎯 更新内容

已将AI智能回复功能集成到商家评论管理页面，商家在回复评价时可以获得AI生成的回复建议。

---

## ✨ 新功能

### 商家回复评价流程

1. **查看评论** - 在评论管理页面查看所有评论
2. **点击回复** - 点击"回复"按钮打开回复弹窗
3. **获取AI建议** - 点击"获取AI智能回复建议"按钮
4. **查看建议** - AI生成3种风格的回复建议：
   - 🔵 专业正式
   - 🟢 友好亲切
   - 🟠 补偿型（针对差评）
5. **选择使用** - 点击"使用此回复"自动填充到输入框
6. **编辑提交** - 可以编辑AI建议的内容，然后提交

## 🔧 技术实现

### 前端更新

**文件**: `src/pages/admin/ReviewManagement/index.jsx`

**新增功能**:
1. AI回复建议状态管理
2. 获取AI建议的处理函数
3. 使用AI建议的处理函数
4. 集成ReplySuggestionsModal组件

**关键代码**:
```javascript
// 状态管理
const [aiSuggestionsVisible, setAiSuggestionsVisible] = useState(false);
const [aiSuggestions, setAiSuggestions] = useState(null);
const [aiLoading, setAiLoading] = useState(false);

// 获取AI建议
const handleGetAISuggestions = async () => {
  const response = await aiApi.generateReplySuggestions({
    hotelId: selectedReview.hotel_id,
    reviewId: selectedReview.id,
    reviewContent: selectedReview.content,
    rating: selectedReview.overall_rating,
    sentiment: selectedReview.sentiment
  });
  setAiSuggestions(response.data);
  setAiSuggestionsVisible(true);
};

// 使用AI建议
const handleUseAISuggestion = (content) => {
  setReplyContent(content);
  setAiSuggestionsVisible(false);
};
```

## 🚀 使用流程

### 步骤1：登录商家账号

```
访问: http://localhost:5173/admin/login
用户名: merchant1
密码: 123456
```

### 步骤2：进入评论管理

点击导航栏的"评论管理"，或访问：
```
http://localhost:5173/admin/review-management
```

### 步骤3：回复评价

1. 在评论列表中找到要回复的评论
2. 点击"回复"按钮
3. 在弹窗中点击"获取AI智能回复建议"
4. 等待AI生成建议（2-3秒）
5. 查看3种风格的回复建议
6. 点击"使用此回复"或"复制"
7. 可以编辑AI建议的内容
8. 点击"提交回复"

### 步骤4：验证回复

返回用户端详情页查看商家回复：
```
http://localhost:5173/detail/1
```

## 🎯 AI回复建议特点

### 3种回复风格

| 风格 | 适用场景 | 语气 | 示例 |
|------|----------|------|------|
| 🔵 专业正式 | 高端酒店、商务客户 | 正式、礼貌 | "尊敬的客人，非常感谢您的宝贵意见..." |
| 🟢 友好亲切 | 休闲酒店、年轻客户 | 随意、温暖 | "感谢您的好评！很高兴您喜欢我们的服务..." |
| 🟠 补偿型 | 差评、投诉 | 道歉、补偿 | "非常抱歉给您带来不便，我们会立即改进..." |

### 智能特性

1. **情感识别** - 根据评价情感（好评/中评/差评）生成对应风格
2. **评分感知** - 根据评分高低调整回复语气
3. **内容分析** - 分析评价内容，针对性回复
4. **多样化** - 提供3种不同风格供选择
5. **可编辑** - AI建议可以作为模板，商家可以修改

### 回复技巧

AI会提供实用的回复建议：
- ✅ 及时回复可以提升用户满意度
- ✅ 感谢用户的反馈
- ✅ 针对具体问题给出解决方案
- ✅ 邀请用户再次光临
- ✅ 保持专业和礼貌的态度
