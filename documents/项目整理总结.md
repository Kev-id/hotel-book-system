## 📖 使用指南

### 新手入门（推荐顺序）

1. **快速体验（5 分钟）**
   ```bash
   # 阅读 QUICK-START.md
   npm install
   cd backend && npm install
   cp .env.example .env  # 修改数据库密码
   node sql/init.js
   npm run dev  # 两个终端分别启动前后端
   ```

2. **详细了解**
   - 阅读 `SETUP.md` 了解详细安装步骤
   - 阅读 `README.md` 了解项目功能
   - 阅读 `PROJECT-STRUCTURE.md` 了解项目结构

3. **开始开发**
   - 阅读 `documents/HANDOVER-GUIDE.md` 了解架构
   - 阅读 `backend/README.md` 了解 API
   - 运行测试脚本验证功能

**旧方式（已废弃）：**
