## 🔧 技术实现

### 前端
- React + Ant Design
- 组件化设计
- 响应式布局
- 状态管理（useState, useEffect）
- API调用（axios）

### 后端
- Express.js
- MySQL数据库
- RESTful API
- JSON字段处理

### API接口
- `GET /api/reviews` - 获取评论列表
- `POST /api/reviews/:id/reply` - 商家回复
- `POST /api/reviews/:id/helpful` - 点赞

## 📝 数据结构

### 评论表 (reviews)
```sql
- id: 评论ID
- user_id: 用户ID
- hotel_id: 酒店ID
- order_id: 订单ID
- overall_rating: 总评分 (1-5)
- dimensions: 维度评分 (JSON)
- content: 评价内容
- images: 图片 (JSON)
- tags: 标签 (JSON)
- sentiment: 情感 (positive/neutral/negative)
- merchant_reply: 商家回复 (JSON)
- helpful: 点赞数
- create_time: 创建时间
```
