# 使用说明

## 快速开始

### 1. 运行数据清理和准备脚本

```bash
cd hotel-book-system-master/backend/sql/database-cleanup-preparation
node cleanup-and-prepare.js
```

### 2. 查看生成的数据

脚本会生成以下数据：

- **订单数据**：50-100个订单，包含不同状态（已完成、已确认、已取消、待确认）
- **评价数据**：为60%的已完成订单生成评价，包含多样化的评分、情感和关键词
- **收藏数据**：每个用户2-4个收藏，基于用户画像
- **价格历史**：过去90天的每日价格记录，包含周末和节假日溢价

### 3. 验证数据

运行以下SQL查询验证数据：

```sql
-- 查看订单统计
SELECT status, COUNT(*) as count 
FROM orders 
GROUP BY status;

-- 查看评价统计
SELECT sentiment, COUNT(*) as count 
FROM reviews 
GROUP BY sentiment;

-- 查看收藏统计
SELECT category, COUNT(*) as count 
FROM favorites 
GROUP BY category;

-- 查看价格历史统计
SELECT COUNT(*) as total_records,
       MIN(date) as earliest_date,
       MAX(date) as latest_date
FROM price_history;
```

## 注意事项

- 脚本会清空orders、reviews、favorites、price_history表
- 用户、酒店、房型数据会被保留
- 可以多次运行脚本，每次生成新的数据
- 生成的数据是随机的，每次运行结果不同

## 故障排除

### 问题：架构验证失败
**解决方案**：运行 `node sql/init.js` 初始化数据库

### 问题：用户表为空
**解决方案**：运行 `node sql/init.js` 创建基础数据

### 问题：数据库连接失败
**解决方案**：检查 `.env` 文件中的数据库配置
