# 数据库清理与数据准备系统

## 概述

这个系统用于清理现有测试数据并生成高质量、多样化的数据集，以支持AI增强功能（任务12/13/14）的演示和测试。

## 功能特性

- ✅ 选择性数据清理（保留用户、酒店、房型）
- ✅ 基于用户画像的订单生成
- ✅ 多样化的评价数据生成
- ✅ 关键词注入以支持AI分析
- ✅ 可疑评价生成（5-10%）
- ✅ 用户收藏数据生成
- ✅ 历史价格数据生成（90天）
- ✅ 事务安全和幂等性

## 快速开始

### 1. 确保数据库已初始化

首先运行基础初始化脚本：

```bash
cd hotel-book-system-master/backend
node sql/init.js
```

### 2. 运行清理和准备脚本

```bash
cd hotel-book-system-master/backend/sql/database-cleanup-preparation
node cleanup-and-prepare.js
```

## 生成的数据

### 订单数据
- 总数：50-100个订单
- 状态分布：
  - 70% 已完成
  - 15% 已确认
  - 10% 已取消
  - 5% 待确认
- 日期范围：过去3个月到未来3个月
- 基于用户画像的真实预订模式

### 评价数据
- 为60%的已完成订单生成评价
- 评分范围：1-5星（倾向于高分）
- 包含5个维度评分（清洁度、服务、位置、设施、性价比）
- 情感分析：正面、中性、负面
- 关键词注入：每个酒店3-5个亮点和槽点
- 可疑评价：5-10%（用于测试AI质量检测）

### 收藏数据
- 每个用户2-4个收藏
- 基于用户画像的酒店选择
- 分类：商务、休闲、家庭、浪漫
- 30%包含备注

### 价格历史
- 过去90天的每日价格记录
- 周末溢价：+30%
- 节假日溢价：+50%
- 工作日波动：±20%
- 包含入住率数据

## 用户画像

系统使用4种用户画像来生成真实的数据模式：

1. **商务旅客**
   - 偏好：市中心、商务区
   - 设施：会议室、WiFi、健身房
   - 预订：工作日，提前7-30天
   - 住宿：1-3晚

2. **家庭度假**
   - 偏好：景区附近、郊区
   - 设施：游泳池、儿童乐园
   - 预订：周末，提前30-90天
   - 住宿：3-7晚

3. **预算旅客**
   - 偏好：性价比高、交通便利
   - 预订：提前1-14天
   - 住宿：1-2晚

4. **奢华追求者**
   - 偏好：五星级酒店
   - 设施：SPA、米其林餐厅
   - 预订：提前30-60天
   - 住宿：2-5晚

## 注意事项

1. **数据清理**：脚本会清空orders、reviews、favorites、price_history表，但保留users、hotels、room_types表
2. **幂等性**：可以多次运行脚本，每次都会生成新的数据
3. **随机性**：每次运行生成的数据都不同（可以通过设置seed参数固定）
4. **性能**：生成100个订单和相关数据大约需要10-30秒

## 故障排除

### 错误：缺失必需的表
运行 `node sql/init.js` 初始化数据库

### 错误：用户表为空
运行 `node sql/init.js` 创建基础用户和酒店数据

### 错误：数据库连接失败
检查 `.env` 文件中的数据库配置
