# 快速使用指南

## 🎯 目的

清理数据库中的多余数据，只保留4个精选酒店，并为这些酒店生成高质量的测试数据，用于演示任务12/13/14的AI功能。

## 📋 使用步骤

### 方法1：完全重置（推荐用于演示）

**清理所有数据（包括酒店），重新创建4个精选酒店**

```bash
cd hotel-book-system-master/backend/sql/database-cleanup-preparation
node cleanup-hotels-and-prepare.js
```

**结果：**
- ✅ 删除所有225个酒店
- ✅ 创建4个精选酒店（北京、上海、广州、深圳）
- ✅ 为每个酒店创建2种房型
- ✅ 生成约100个订单
- ✅ 生成约30条评价（包含关键词和可疑评价）
- ✅ 生成约100条收藏
- ✅ 生成约700条价格历史记录

### 方法2：保留现有酒店

**只清理订单/评价/收藏/价格历史，保留现有酒店**

```bash
cd hotel-book-system-master/backend/sql/database-cleanup-preparation
node cleanup-and-prepare.js
```

**结果：**
- ✅ 保留现有的225个酒店
- ✅ 清理并重新生成订单、评价、收藏、价格历史

## ⚠️ 注意事项

1. **数据会被完全清理** - `cleanup-hotels-and-prepare.js` 会删除所有酒店和相关数据
2. **用户数据保留** - 用户账户不会被删除
3. **可以多次运行** - 脚本是幂等的，可以重复运行
4. **执行时间** - 大约需要1-2秒

## 🔧 故障排除

### 问题：架构验证失败
**解决方案：** 运行 `node sql/init.js` 初始化数据库

### 问题：用户表为空
**解决方案：** 运行 `node sql/init.js` 创建基础用户数据

### 问题：数据库连接失败
**解决方案：** 检查 `.env` 文件中的数据库配置
